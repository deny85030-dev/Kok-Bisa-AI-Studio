## 📖 Tentang Proyek

**Kok Bisa? Studio AI** adalah alat berbasis web yang membantu kreator konten edukasi membuat naskah narasi mengalir (continuous storytelling) dengan bantuan AI. Dirancang khusus untuk channel edukasi bergaya *"Kok Bisa?"*, alat ini memandu Anda dari pencarian topik hingga metadata SEO siap upload ke YouTube.

### ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🔍 **Google Search Live** | Temukan topik trending menggunakan grounding Google Search via Gemini API |
| 🎨 **Dual Format Support** | Pilih antara 16:9 (Long-form) atau 9:16 (Shorts/Reels) |
| 📝 **Continuous Script Generator** | Buat naskah narasi mengalir tanpa potongan judul bab rigid |
| 🖼️ **Visual Prompt Generator** | 8 gaya visual siap pakai (Realistik, Flat Vector, 3D Pixar, Anime, dll) |
| 🎬 **Image-to-Video Prompts** | Prompt siap pakai untuk Runway Gen-2 / Luma Dream Machine |
| 📸 **Thumbnail Studio** | Prompt cover dengan tipografi besar dan kontras tinggi |
| 📈 **YouTube SEO** | 5 opsi judul, deskripsi, tags, dan komentar pin otomatis |
| 🔐 **API Key Management** | Simpan Gemini API Key secara lokal (tidak disimpan di server) |

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Font:** Inter (Google Fonts)
- **Icons:** Lucide Icons
- **AI Engine:** Google Gemini API (`gemini-2.5-flash`)
- **Image Generation:** Google Imagen (opsional)
- **Search:** Google Search Grounding
